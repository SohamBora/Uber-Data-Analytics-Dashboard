# Uber Data Analytics Dashboard | Power BI

## Project Overview

The **Uber Data Analytics Dashboard** is a data analytics project developed using Microsoft Power BI to analyze ride-booking data and identify trends in revenue, bookings, cancellations, trip performance, and customer demand.

The project focuses on transforming raw ride records into meaningful business insights through data cleaning, DAX-based calculations, and interactive visualizations.

## Objectives

- Analyze Uber ride-booking data to understand business performance.
- Clean and transform raw data using Power Query.
- Develop key performance indicators (KPIs) using DAX.
- Track revenue, bookings, cancellations, and trips.
- Identify peak-demand periods and cancellation patterns.
- Present actionable insights through interactive dashboards.

## Tools and Technologies

- **Microsoft Power BI** — Dashboard development and data visualization.
- **Power Query** — Data cleaning and transformation.
- **DAX (Data Analysis Expressions)** — KPI calculations and analytical measures.
- **Data Analytics** — Trend analysis and business performance reporting.

## Dataset

The project involves **100,000+ raw Uber ride records**, as described in the project scope.

The data is processed to support analysis of ride-booking activity, revenue, cancellations, and demand patterns.

## Project Workflow

1. **Data Preparation**
   - Imported the raw ride data into Power BI.
   - Used Power Query to clean and structure the data.
   - Prepared the data for analysis and reporting.

2. **Data Modeling and Measures**
   - Created DAX-based measures for key performance indicators.
   - Organized analytical measures to support dashboard reporting.

3. **Dashboard Development**
   - Built interactive Power BI dashboards.
   - Presented metrics related to revenue, bookings, cancellations, and trips.
   - Enabled exploration of ride trends and demand patterns.

4. **Insights and Analysis**
   - Examined cancellation trends.
   - Identified periods of peak demand.
   - Used visual analytics to support data-driven operational decisions.
